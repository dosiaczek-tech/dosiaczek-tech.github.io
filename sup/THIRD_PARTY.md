# Dane OpenStreetMap

`data/route-map.geojson`, `data/water-areas.geojson` i `data/waterways-reference.json`: © OpenStreetMap contributors,
[Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Źródło: https://www.openstreetmap.org/copyright, API Nominatim i API OpenStreetMap.

Część rekordów `data/access-points.json` również pochodzi z OpenStreetMap
i podlega ODbL. Każdy taki rekord wskazuje oryginalny obiekt OSM.
Pozostałe lokalizacje są faktami z publicznych map operatorów i obiektów, opisów
regionalnych i przewodników (PSK, Włocławski Klub Wodniaków PTTK, Packraft.pl,
Kajaczkowo, Kajaki Wkra Arka i źródła przy poszczególnych punktach). Przybliżenia
wyprowadzone z opisu, kilometrażu lub położenia bazy są oznaczone wraz z metodą.
Opisy dostępu są
autorskimi streszczeniami. Autor, odnośnik oraz data odczytu znajdują się w `sources`
przy każdym miejscu. Mapy operatorów i ich zdjęcia nie są kopiowane do interfejsu.
